Built by \*\*João Gonçalves\*\* — Technical Sales Consultant \& IT Support Specialist with 10+ years of hands-on experience in hardware/software diagnostics, technical discovery, consultative solution recommendations, and post-sales support across US and European markets.

\## Scope \& Disclaimer

\- \*\*Real-World Experience vs. Lab Environments:\*\* Real-world troubleshooting cases are clearly separated from simulated lab implementations.

\- \*\*Simulated POCs:\*\* All Proofs of Concept and enterprise environments in this repository are lab-based simulations created to validate technical feasibility, document architecture decisions, and demonstrate structured Go / No-Go evaluation criteria.

\- \*\*Security:\*\* No production credentials, API keys, tokens, or private client data are stored in this repository.
